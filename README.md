Figgy Bank — Banking Management Application
Figgy Bank is a C#/.NET console-based banking application designed to simulate core customer and administrative banking workflows. The application allows customers to manage savings and checking accounts, perform deposits, withdrawals and transfers, review transaction history, request cheque books, and manage account credentials. Administrative functionality includes account management, password resets, account summaries, and cheque-book request approvals.

Built using C#, .NET, Entity Framework Core, and SQL Server, the project applies object-oriented programming principles including abstraction, inheritance, encapsulation, and polymorphism. EF Core provides persistent data storage and manages relationships between customers, accounts, transactions, and cheque-book requests.

This project strengthened my understanding of application architecture, relational database design, ORM-based data access, entity relationships, and persistent CRUD operations, while giving me practical experience connecting a C# application to a SQL Server database.

Technologies: C# · .NET · Entity Framework Core · SQL Server · LINQ · OOP

Key Features: Customer & Admin workflows · Savings & Checking accounts · Deposits & withdrawals · Account transfers · Transaction history · Password reset workflow · Cheque-book requests · Persistent database storage
